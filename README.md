# Washi — beta grátis

**Photoshop + Figma num app só, com IA trabalhando direto nas camadas.**
Pincel, máscara, vetor e texto editáveis: a IA monta a peça e você termina do seu jeito.

## ⬇️ Baixar

1. Abra **[Releases](https://github.com/mathiassjesus1-spec/washi-beta/releases/latest)**.
2. Baixe o arquivo `Washi-0.8.0-instalador.exe` (Windows 10/11, 64 bits).
3. Dê dois cliques e siga o instalador.

## ⚠️ O Windows avisou "O Windows protegeu o computador"?

**É esperado.** Estamos finalizando a assinatura do Washi na **Microsoft Store**. Até ela sair, o Windows não reconhece o instalador e mostra esse aviso.

Para instalar:
1. Clique em **Mais informações**.
2. Clique em **Executar assim mesmo**.

Baixe **só por esta página**. Não use cópias de outros sites.

## 🔒 Confira se o arquivo é o original

Cada versão vem com o `SHA256SUMS.txt`. No PowerShell, na pasta do download:

```powershell
Get-FileHash .\Washi-0.8.0-instalador.exe -Algorithm SHA256
```

O código tem que ser **igual** ao do `SHA256SUMS.txt`. Se for diferente, não instale e nos avise. Veja também a [política de segurança](SECURITY.md).

## 🗓️ Validade do beta

Este beta é **gratuito** e vale até **30/11/2026**. Nos últimos 7 dias o app avisa. Depois disso, ele pede a versão nova, e os seus projetos (`.atelier`) continuam no seu computador.

## 🤖 IA

A IA usa a **sua chave do OpenRouter** (dá para usar os modelos gratuitos) ou um plano Washi. Os geradores de imagem e vídeo são os que você escolher no painel.

## 🐞 Achou um erro?

Abra uma **[Issue](https://github.com/mathiassjesus1-spec/washi-beta/issues)** ou comente no vídeo. Cada erro relatado no beta é corrigido.
